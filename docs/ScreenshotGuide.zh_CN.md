# Deskflow 截图同步使用指南

这个功能用一个后台热键截取屏幕，直接存进内置 Syncthing 管理的同步文件夹，再由 Syncthing 自动同步到另一台配对电脑。整个过程不弹窗、不提示，和 Ubuntu 的 Flameshot 全屏截图、Windows 的 ShareX 一样安静。

## 绑定热键

截图动作挂在 Deskflow 原有的热键系统上，所以要先给它绑定一个快捷键：

1. 在主界面进入 `高级 → 显示完整界面`，再打开 `Configure Server → Hotkeys`。
2. 新建一个热键，按下你想用的组合键（例如 `Control+Alt+S`）。
3. 在动作类型里选择 **截图并保存到同步文件夹**（英文界面为 `Take a screenshot into the sync folder`），保存。

此后在主机上按下这个组合键，就会截一次图。

## 保存位置

默认存到同步文件夹 `Deskflow Sync` 下的 `screenshots/` 子目录，文件名是 `<主机名>-<时间戳>.png`。只要两台电脑已经配对、Syncthing 正在运行，另一台电脑的同一相对位置很快就会出现同一张图。

截取的是主显示器的整屏。

### 修改保存位置

主页"文件同步"卡片里的 **截图保存到** 一行显示当前位置。这一行只出现在接键盘鼠标的那台电脑上，因为截图由它的热键触发。点 **更改...** 可以重新选择：

- **同步文件夹**：只列出真正会同步出去的文件夹，也就是至少共享给了另一台电脑、并且本机不是"仅接收"的文件夹。选在这里的位置一定会同步。
- **子文件夹**：同步文件夹里面的相对路径，例如 `screenshots` 或 `截图/课堂`，留空就直接存在同步文件夹根目录。不能填绝对路径，也不能用 `..` 跳出同步文件夹。

想把截图放到别的地方，推荐这样做：

1. 点 **文件同步高级设置...**，在打开的 Syncthing 网页里 **添加文件夹**，选好路径，并在"共享"页勾选另一台电脑。另一台电脑会自动接受，存到它的主目录下。
2. 回到 Deskflow 主页，点 **更改...**，在下拉框里选这个新文件夹。

Deskflow 只记住"哪个同步文件夹 + 子文件夹"，不记绝对路径，每次截图前都会向 Syncthing 查询这个文件夹现在的真实位置。Syncthing 网页里已有文件夹的路径是只读的（这是 Syncthing 防止误删数据的设计，Deskflow 没有改动它）。如果文件夹被删除后用同一个文件夹 ID 在别处重新添加，截图位置会自动跟过去。注意配对时开启了自动接受，所以在一台电脑上删除共享文件夹后，另一台电脑会很快把它重新共享回来，并自动放到主目录下的 `Deskflow Sync`。

### 暂时不会同步时

如果所选文件夹已经不在 Syncthing 里、没有共享给另一台电脑，或者文件同步已关闭，截图仍然会保存到这个文件夹上次已知的位置，不会丢。主页会在 **截图保存到** 下方用蓝字说明原因；截图时也会弹出通知（系统托盘可用时）。

## 各平台的"安静"程度

- **X11（多数 Ubuntu）和 Windows**：完全静默，不弹任何窗口。
- **macOS**：系统要求先在 `系统设置 → 隐私与安全性 → 屏幕录制` 里授权一次，之后静默。
- **Wayland（GNOME/KDE）**：走系统的截图门户（`org.freedesktop.portal.Screenshot`，已设为非交互）。GNOME 下静默；KDE 第一次可能弹一次授权，允许后会被记住。这是系统的安全限制，代码无法绕过。

## 限制

和 Flameshot、ShareX 一样，有些内容截出来会是黑块，这是系统层面的保护，不是故障：

- 受版权保护的播放内容（例如浏览器里的流媒体视频）。
- 主动把自己排除在截图之外的程序（部分密码管理器、网银、会议软件）。
- 独占全屏的游戏、Windows 的 UAC 确认框等独立桌面画面。

桌面、网页和普通软件都能正常截取。
