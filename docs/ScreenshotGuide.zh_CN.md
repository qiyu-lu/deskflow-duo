# Deskflow 截图同步使用指南

这个功能用一个后台热键截取屏幕，直接存进内置 Syncthing 管理的同步文件夹，再由 Syncthing 自动同步到另一台配对电脑。整个过程不弹窗、不提示，和 Ubuntu 的 Flameshot 全屏截图、Windows 的 ShareX 一样安静。

## 绑定热键

截图动作挂在 Deskflow 原有的热键系统上，所以要先给它绑定一个快捷键：

1. 在主界面进入 `高级 → 显示完整界面`，再打开 `Configure Server → Hotkeys`。
2. 新建一个热键，按下你想用的组合键（例如 `Control+Alt+S`）。
3. 在动作类型里选择 **截图并保存到同步文件夹**（英文界面为 `Take a screenshot into the sync folder`），保存。

此后在主机上按下这个组合键，就会截一次图。

## 保存位置

图片存到同步文件夹下的 `screenshots/` 子目录，文件名是 `<主机名>-<时间戳>.png`。只要两台电脑已经配对、Syncthing 正在运行，另一台电脑的同一目录很快就会出现同一张图。

截取的是主显示器的整屏。

## 各平台的"安静"程度

- **X11（多数 Ubuntu）和 Windows**：完全静默，不弹任何窗口。
- **macOS**：系统要求先在 `系统设置 → 隐私与安全性 → 屏幕录制` 里授权一次，之后静默。
- **Wayland（GNOME/KDE）**：走系统的截图门户（`org.freedesktop.portal.Screenshot`，已设为非交互）。GNOME 下静默；KDE 第一次可能弹一次授权，允许后会被记住。这是系统的安全限制，代码无法绕过。

## 限制

和 Flameshot、ShareX 一样，有些内容截出来会是黑块，这是系统层面的保护，不是故障：

- 受版权保护的播放内容（例如浏览器里的流媒体视频）。
- 主动把自己排除在截图之外的程序（部分密码管理器、网银、会议软件）。
- 独占全屏的游戏、Windows 的 UAC 确认框等独立桌面画面。

桌面、网页和普通软件都能正常截取。
